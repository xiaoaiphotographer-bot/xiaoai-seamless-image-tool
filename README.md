# 小埃的无缝切图工具 · 无缝切图

Windows 10 / 11 64 位桌面软件。照片在本机处理，无需账号。

下载版解压后，双击 **小埃的无缝切图工具.exe** 即可使用，不需要安装 Python。请保留同目录的 `_internal` 文件夹。

1. 拖入一张图片，或点击「导入图片」。
2. 选择 Instagram 横向连续切图，或微信四格、横向六格、竖向六格、九格。
3. 拖动图片调整位置，滚轮缩放；拖动画框上方的圆点旋转，也可以输入角度或按住 Alt 拖动。
4. 点击「选择目录并导出」，在系统弹窗中选择目标目录。
5. 软件会新建一个文件夹，按 01、02、03… 编号保存切图。按编号顺序发布即可。

Instagram 可选择 2–20 张，提供 1:1、4:5、3:4、16:9 单张比例。微信单张为正方形。

「自动铺满画框」会防止旋转或移动后露出空白；关闭后可自由缩小和移动。「完整显示」会保留整张原图并留白。透明背景自动使用 PNG；JPG 使用白色或黑色背景。

可导入 JPG / JPEG / JFIF、PNG、WebP、TIFF、BMP、GIF、AVIF、ICO、TGA、PPM / PGM / PBM、JPEG 2000，以及 PSD 的合成图。动画和多页图片使用第一帧 / 第一页。

HEIC / HEIF / HIF 和 JPEG XR 通过 Windows 已安装的系统解码器读取。HEIC 通常需要 Microsoft Store 的 HEIF 图像扩展和对应 HEVC 扩展；当前电脑没有所需解码器时，软件会提示。此功能不附带第三方 HEVC 编解码库。

可导出 JPG、PNG、WebP，每张宽度 720 / 1080 / 1440 / 2160 像素。画面先统一变换，再按整数边界切割，没有重叠、漏像素或人为间隔。PNG 支持无损拼回完整画面；JPG / WebP 会进行有损压缩。平台展示间距和发布后的重新压缩由平台决定。

每次导出都创建新文件夹，原图保持不变。可取消导出。图片中的原始 EXIF / GPS 元数据不写入切图，输出使用 sRGB 色彩配置。

最大输入为 8000 万像素、512 MB；总输出最大 7200 万像素。超出时会提示降低尺寸或张数。大图的实际处理速度与内存需求取决于电脑配置。

快捷键：Ctrl+O 导入，Ctrl+E 导出，Ctrl+0 重置，Ctrl+Z 撤销，Ctrl+Y 重做。双击画布居中图片。

发布参考资料放在每次导出的「发布参考」子文件夹中；只上传上一级中的编号图片。

本程序原创源码采用 MIT 许可证。Qt / PySide6 / shiboken6 及其他依赖按各自许可证提供。完整许可证、Qt / PySide 对应源码、安全核查范围及测试记录随下载版附带。用户可以替换 Qt 动态库、修改源码并重新构建；不限制为调试这些修改而进行的逆向工程。

## 从源码运行或构建

安装 Python 3.12 64 位后，在源码目录中安装 `requirements.txt` 里的依赖，运行 `main.py`。双击「构建软件.cmd」会在本地构建独立桌面版。首次安装构建依赖需要网络；运行软件本身不需要。

运行 `python -m unittest discover -s tests -v` 可验证图像处理逻辑。在任意已有测试目录中，使用 `小埃的无缝切图工具.exe --verify <目录>` 可运行打包版界面和导出自检。自检使用程序绘制的示例图，不读取用户图库。正常双击启动不会运行自检。
